On Earth, fire rises. In free fall, it doesn't.

NASA flew acrylic rods in a small wind tunnel on the Space Station and stepped the oxidiser flow down until the flame went out. The published analysis says that near the limit the flame grows longer, dimmer and turns from yellow to blue. True, peer-reviewed, and never measured frame by frame. FLARE-X is the measurement layer that makes it measurable — with an error bar on every number and a chain back to the file it came from.

The protocol is a staircase, and that is what makes this falsifiable

Ignition at high flow, then the commanded oxidiser velocity stepped down with a quasi-steady dwell at each level, until extinction. Every riser is an externally imposed event, so the transitions FLARE-X detects from imagery alone can be scored against something the pixels did not produce.

02

Segmentation that survives the blue flame

Almost every off-the-shelf fire detector keys on the red channel. The near-limit flame is dim and blue, so a red-channel rule suppresses the flame exactly where the science is. FLARE-X segments on a soot-independent radiance proxy and measures colour separately, as the sootiness index χ = (R−B)/(R+B).

χ is a colour index, not a temperature. The BASS-II video camera was not radiometrically calibrated and the in-duct thermopile radiometer is documented by NASA as uncalibrated. No function in this project converts brightness to temperature, heat release or soot volume fraction — the channel is named radiance_proxy so the constraint cannot be forgotten.
03

Morphology, resolved against the flow axis

Area, flow-axis length, aspect ratio and standoff — measured against the duct geometry, not the image axes, so a rotated camera does not change the physics. A dark frame returns None, not a zero-area flame: an absent flame is a gap in the record, which is a different thing from a flame of zero size.

04

Combustion states, from rules you can check by hand

Change-point detection plus explicit inequalities. No learned parameters, so nothing can silently memorise a dataset and every boundary traces to a comparison a reviewer can verify. A supervised classifier is only justified once it beats this on held-out labels — those labels do not exist yet, so no model is shipped.

Why each term is in the index
One branch only. Flame spread rate is non-monotonic in opposed flow velocity — it rises, then falls. The monotonicity check is only meaningful below the turning point. Applying it across the full flow range would be a misuse of it.
06

Why removing gravity removes a transport channel

Gravity enters through the body-force term, so the Grashof number scales linearly with g and the buoyant velocity scale as √g. These are computed from inputs you can see and change — and the functions refuse to run without them.

The mechanism is published, not ours. At very low flow
  the flame is weak and stands off behind a thickened boundary layer. Heat transfer to the
  solid falls, surface re-radiation comes to dominate the energy balance, and oxygen
  transport becomes limiting — the radiative / transport-limited extinction branch. FLARE-X
  measures appearance consistent with that mechanism. Consistency is not confirmation.

    Two defects this harness caught
    
    
    
      
    25 false-positive frames after extinction.
      Otsu's method returns a threshold on any input, including pure sensor noise. That defect
      would have corrupted every extinction time the system produced. Fixed with a detection
      gate set relative to the extreme-value noise scale σ√(2 ln N) — about 5σ over a 760×480
      frame, so a fixed “6σ” rule sits barely above the noise ceiling — plus an
      independent noise floor on the hysteresis growth threshold.
    
      
    A falsely confident error bar.
      Sweeping only the high hysteresis threshold reported ≈0 % segmentation uncertainty,
      correctly — in hysteresis thresholding the grown region is set by the low
      threshold, so that sweep was nearly a no-op. Both thresholds now move together, giving
      the 3.1 % figure actually used in the budget.
